# Basketball Management Application

## Introduction
The Basketball Management Application is designed to help manage basketball teams, games, workouts, and player statistics. The platform provides different levels of access based on user roles, ensuring a secure and efficient workflow for administrators, coaches, players, and fans.

## Features
### User Management
- **Authentication:** Users can register, log in, and reset their passwords.
- **Profiles:** Personalized user profiles with relevant information.
- **Permissions & Roles:** A robust permission system with different access levels:
  - **Admin:** Full access to all functionalities.
  - **Manager:** Can create, delete, and modify games, schedule workouts, and manage players.
  - **Coach:** Can add and remove workouts, view player/game details, and assign players to workouts.
  - **Assistant:** Same as Coach but **cannot** create workouts.
  - **Player:** Can view match details, their own stats, and workout schedules.
  - **Normal User:** Can only see upcoming games and player statistics.
- **403 Page:** Restricted access handling for unauthorized users.
